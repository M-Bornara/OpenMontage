# Oddly Matt — claude.ai Project kit

How to set up the "Oddly Matt" Project in claude.ai. Re-upload the knowledge files after a big plan change
(about once a month); day-to-day state is read live from the repo.

## 1. Create the Project
claude.ai → Projects → New project
- Name: **Oddly Matt**
- Description: "Run the Oddly Matt channel: social media, reviews, captions, comments and growth across YouTube,
  TikTok, Instagram and Facebook."
- Instructions: paste the part of `project-instructions.md` below the line.

## 2. Upload these files as Project knowledge
From `E:\Projects\OpenMontage\channels\storybook-medical\`:

| File | Why |
|---|---|
| `claude-project/00-start-here.md` | the map: channel, accounts, releases, files |
| `plan/social-plan.md` | the platform plan |
| `plan/growth-strategy.md` | formats, cadence, YouTube triggers |
| `plan/promotion-research.md` | what promotion is allowed |
| `plan/comment-challenges.md` | comment questions and safety gate |
| `plan/master-instructions-v3.md` | governing rules (brand, editorial standard) |
| `plan/branding-checklist.md` | identity, bios, copy |
| `plan/story-craft.md` | how the stories are told (for captions and hooks) |
| `plan/thumbnail-craft.md` | packaging rules |
| `editorial/templates/analytics-review.md` | review template |
| `editorial/claim-decisions.md` | settled wording for disputed facts |

Don't upload `open-items.md` or `upload-schedule.md`: they change every day, so the Project reads them live.

## 3. Skills
Save the three skills proposed in chat (weekly review, platform captions, comment sweep). They work in any chat,
including this Project.

## 4. Each chat
Open the chat from the Claude desktop app on the XPS so it can reach the repo folder and the Oddly Matt Chrome profile.
