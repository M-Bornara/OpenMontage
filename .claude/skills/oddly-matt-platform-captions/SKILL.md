# Oddly Matt platform captions (v2, 2026-11-20; repo copy is the source of truth)

The package is generated by `editorial/episodes/<ID>/publish_<id>.py` through `scripts/publish_social.py` into
`projects/<id>/renders/deliverables/publish.md` (+ publish.json). This skill is the rulebook: write the texts into
the episode's publish script, run it, then show Mahdi the blocks. Never post or schedule.

## Facts
Every fact must be VERIFIED or ATTRIBUTED in `editorial/episodes/<ID>/claims.csv`; DISPUTED keeps its dispute
wording; REMOVE/UNKNOWN never appear. "About" stays where the claim says about. No medical advice; the description
ends with the history-not-medical-advice line.
**Claim IDs (2026-11-21):** every public sentence in the publish script ends with its tag (`[C06]`, `[C19 C25]`,
`[NF]` for a question / CTA / disclaimer, `[HCS10:C45]` for another episode's log); `scripts/claim_tags.py` fails the
script on a missing tag or an UNKNOWN / REMOVE ID and strips the tags before episode.json.
**Fact gate (HARD RULE):** before Mahdi sees the captions or the package, run the independent fact gate
(`plan/fact-gate.md`): a fresh sub-agent with ONLY claims.csv + `fact-gate/package*.md`; fix its flags, re-run until
clean, show its table with the text.

## Voice and hooks
Matt's voice: curious, warm, a little playful, short sentences, no hype ("insane", "you won't believe"), no bait.
Lead with the strange act or the danger, not the place. For stories from Iran, the country stays out of the hook,
first caption line, cover and hook card; it stays in the description facts (user decision 2026-11-17). Never
"Persia" for anything before ~550 BC.

## Per platform
| Field | YouTube Shorts | TikTok | Instagram | Facebook |
|---|---|---|---|---|
| First line | title (C009: one person + one strange act, or a question) | the hook in searchable words | the hook, < 125 chars | a plain opener that works without sound |
| Body | full description + SOURCES + CREDITS | 1 short line | 1-2 lines + source name | 2-3 lines of context |
| CTA | Related video does it | "More true stories on YouTube: Oddly Matt" | "…(link in bio)" | "…: oddlymatt.com" |
| Hashtags | 3 | 3-5 | **max 5** (Instagram's limit) | 1-3 |
| Playlist | Season Zero + the cluster playlist | none | none | ONE playlist only |
Tags: a few precise ones (YouTube says tags play a minimal role). Times in ET and Alberta.

## Also in every package
- `hook_card:` (v2.1: 4-8 words, max 2 lines, 1 amber word, no spoiler, nothing DISPUTED as fact), CASE chip
  number in release order, end line "More strange cases: follow Oddly Matt".
- First comment per platform = the comment challenge (plan/comment-challenges.md) + the platform's CTA line.
  Exact lines: `scripts/publish_social.py` CAPTION_CTA / COMMENT_CTA; `lint_captions` fails the package (run in
  `publish_social.finish()`; call `publish_social.check(pub)` before writing episode.json) when a caption or first
  comment lacks its CTA line or the first comment is pasted into the caption (user, 2026-11-21).
  First comments can't be scheduled: Mahdi posts and pins them when each post goes live.
- Credits for CC-BY sounds and archive images in the description.
- Per-platform blocks are change C001 in plan/change-log.csv; don't change the format without a new change row.
